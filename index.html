Publicar en GitHub Pages
El sitio es estático: GitHub Pages no almacena comentarios ni cambios hechos en otros dispositivos. Para compartir la versión final, haz lo siguiente:
  1. Trabajen los cambios en un mismo navegador, o intercambien el archivo ferreksa-acuerdos.json usando «Respaldar» e «Importar».
  2. Pulsen Actualizar versión dueños y revisen las 15 láminas de dirección.
  3. Descarguen presentacion-duenos.html y el respaldo JSON.
  4. Suban ambos archivos al repositorio público junto a este index.html.
  5. En GitHub → Settings → Pages, publiquen desde la rama main, carpeta raíz. La presentación pública queda en https://usuario.github.io/repositorio/presentacion-duenos.html.
Para edición simultánea con sincronización automática entre dispositivos se necesitaría un backend con autenticación, por ejemplo Supabase o Firebase. No se incluyen contraseñas ni tokens de GitHub en esta página pública.
